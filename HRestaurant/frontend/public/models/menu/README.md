# Menu GLB assets

Place optimized production models here, for example `classic-burger.glb`, `caesar-salad.glb`, and `rice-dish.glb`. Do not commit placeholder binaries. Prefer GLB under 5–8 MB, baked PBR textures, a centered origin, real-world scale, and Draco or Meshopt compression. Named ingredient nodes such as `TopBun`, `Lettuce`, `Tomato`, `Cheese`, `Patty`, `Sauce`, and `BottomBun` enable the optional exploded view.
